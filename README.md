Expense Tracker

A simple and user-friendly Expense Tracker built using HTML, CSS, and JavaScript.

About the Project

The Expense Tracker is a browser-based application that helps users record and manage their daily expenses. It provides an easy way to keep track of spending and view total expenses.

Features

- Add new expenses
- Enter expense names and amounts
- View a list of recorded expenses
- Calculate total expenses
- Delete expenses
- Simple and responsive user interface

Technologies Used

- HTML
- CSS
- JavaScript

How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open "index.html" in your web browser.
4. Start recording your expenses.

Learning Outcomes

- Practiced JavaScript functions and event handling.
- Learned DOM manipulation.
- Worked with arrays and calculations.
- Improved HTML and CSS skills.
